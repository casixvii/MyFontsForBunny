# MyFontsForBunny
My cool fonts for you to add to your Discord client!!
---
how to add:
- copy ``https://raw.githubusercontent.com/casixvii/MyFontsForBunny/main/<font>.json``
- replace "\<font>" with whatever font you may choose (e.g. replace with googlesans for Google Sans)
- find the fonts section in whatever Discord app client you use
- click on **Import font entries from a link**
- paste in the link you've just created & click Import
- scroll down and press Import again
